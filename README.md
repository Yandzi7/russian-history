# История России — Материалы и Тесты

Образовательный портал и база справочных материалов по отечественной истории с интерактивным тренажёром тестов.

## Разделы

- **Конспекты**: структурированная теория по 8 историческим эпохам (от расселения восточных славян в IX веке до 2020-х гг.) с хронологией, ключевыми деятелями и терминами.
- **Культура (Задания №15–16 ЕГЭ)**: систематизированный каталог архитектурных памятников, живописи, иконописи и скульптуры с датировками, авторами и особенностями для экзамена.
- **Всемирная история (Задания №2 и №21 ЕГЭ)**: синхронистическая таблица параллелей всемирной и отечественной истории (V–XX вв.).
- **Словарь понятий (Задание №19 ЕГЭ)**: термины с точными академическими определениями и конкретизирующими историческими фактами.
- **Тренажёр тестирования**: банк вопросов с разбивкой по эпохам и темам, мгновенной проверкой, объяснениями и режимом работы над ошибками.

## Особенности

- Быстрый поиск по всем материалам курса (`Ctrl + K`).
- Горячие клавиши в тестах (`1–4` для выбора ответа, `Enter` для перехода к следующему вопросу).
- Тёмная и светлая темы оформления.
- Автоматическое сохранение прогресса изучения в браузере (`localStorage`).

## Стек технологий

- React 19 + TypeScript
- Vite
- Lucide React (иконки)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build

# Предпросмотр production-сборки
npm run preview
```
